# calendarbackup-report

Usa questa skill per report finale, chiusura sessione, follow-up, comunicazione con Matteo,
spiegazioni semplici e separazione file letti/modificati.

Fonti da leggere quando serve:

1. `docs/COMUNICAZIONE_UTENTE_SKILL.md`
2. `docs/Comunicazione-Skill/VOCABOLARIO.md`
3. `docs/FOLLOW_UP.md` se ci sono debiti o follow-up.

Regole:

- Parla per schermate e flussi concreti.
- Separa file letti da file modificati.
- Separa test eseguiti da test non eseguiti.
- Non inventare comandi, log o risultati.
- Se non hai verificato qualcosa, dichiaralo.
