# calendarbackup-menu-qr

Usa questa skill per Menu QR pubblico, menu digitale, QR code, foto piatti, categorie menu e pagina
mobile menu.

Fonti da leggere quando serve:

1. `docs/Menu-QR-Skill/MENU_QR_SKILL.md`
2. File `contesto/` indicati da `MENU_QR_SKILL.md`
3. `docs/per-ui-design-skill/UI_RESPONSIVE_SKILL.md` per layout mobile.
4. `docs/per-ui-design-skill/UI_EDIT_SKILL.md` per stile/componenti.

Divieti:

- Non confondere Menu QR con Pagina Prenota.
- Non toccare flusso prenotazione se il task riguarda solo menu.
- Non cambiare schema dati menu senza skill DB e verifica senior.
