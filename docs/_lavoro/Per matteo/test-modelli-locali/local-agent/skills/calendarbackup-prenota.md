# calendarbackup-prenota

Usa questa skill per Pagina Prenota, `BookingRequestPage`, form pubblico, card tipologia, sub-tabs,
sfondo, layout mobile, data/ora e riepilogo.

Fonti da leggere quando serve:

1. `docs/Prenota-Skill/PRENOTA_SKILL.md`
2. `docs/per-ui-design-skill/UI_RESPONSIVE_SKILL.md` per layout/mobile/breakpoint.
3. `docs/per-ui-design-skill/UI_EDIT_SKILL.md` per classi, tema, componenti o stile.
4. `docs/Prenota-Skill/contesto/PRENOTA_DATA_FLOW_CONTEXT.md` per dati, tipologie, sub-tabs o capability.

Divieti:

- Non confondere Pagina Prenota con Menu QR.
- Non toccare DB o flusso prenotazione se il task e solo layout.
- Non cambiare logica capability-driven con logica basata su nomi hardcoded.
