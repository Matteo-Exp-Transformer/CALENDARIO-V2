# calendarbackup-testing-verifier

Usa questa skill per verifica, debug, review report, review diff, test dichiarati, QA responsive e
controllo scope.

Fonti da leggere quando serve:

1. `docs/Testing-Skill/TESTING_SKILL.md`
2. Skill d'area del diff o del report.

Regole:

- Separa test dichiarati da test verificati.
- Non approvare test senza output reale o log.
- Per UI/responsive richiedi QA su mobile, tablet e desktop.
- Se il report non cita skill obbligatorie, segnala rischio.
- Se il diff tocca file fuori scope, segnala file, rischio e azione consigliata.
