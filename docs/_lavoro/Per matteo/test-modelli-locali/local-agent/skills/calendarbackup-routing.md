# calendarbackup-routing

Usa questa skill per qualsiasi task su CalendarBackup-v2 prima di scegliere area, file, piano o
modifica.

Istruzioni:

1. Parti da `AGENTS.md`.
2. Leggi `docs/APP_CONTEXT_SKILL.md` §0 solo quando serve routing reale.
3. Leggi `docs/Comunicazione-Skill/VOCABOLARIO.md` se devi interpretare parole comando di Matteo.
4. Identifica profilo: planner, executor, verifier o architect.
5. Identifica area e skill d'area.
6. Non navigare il codice a tappeto.

Output minimo:

- Profilo scelto.
- Area probabile.
- Skill da leggere.
- File letti.
- Inferenze.
- Non verificato.
