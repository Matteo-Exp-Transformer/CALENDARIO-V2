# CalendarBackup routing

Questa skill e l'entry point Roo per CalendarBackup-v2. Non sostituisce le skill della repo: instrada
verso i file corretti.

## Quando usarla

Usala all'inizio di ogni task sulla repo, in qualsiasi mode.

## Istruzioni

1. Leggi `AGENTS.md`.
2. Leggi `docs/APP_CONTEXT_SKILL.md` §0.
3. Leggi `docs/Comunicazione-Skill/VOCABOLARIO.md`.
4. Identifica profilo: planner, executor, verifier o architect.
5. Identifica area e skill d'area.
6. Non aprire file applicativi prima della skill d'area.
7. Non navigare il codice a tappeto.

## Output minimo

- Profilo scelto.
- Area o schermata probabile.
- Skill da leggere.
- File letti.
- Inferenze.
- Non verificato.
