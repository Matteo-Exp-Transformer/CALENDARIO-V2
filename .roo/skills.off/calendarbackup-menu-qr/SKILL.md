# CalendarBackup Menu QR

Questa skill instrada i task sul Menu QR pubblico.

## Quando usarla

Usala per task su:

- Menu QR pubblico;
- QR code;
- menu digitale;
- foto piatti;
- categorie menu;
- layout mobile menu;
- pagina pubblica del menu.

## Fonti da leggere

1. `docs/Menu-QR-Skill/MENU_QR_SKILL.md`
2. File `contesto/` indicati da `MENU_QR_SKILL.md`
3. `docs/per-ui-design-skill/UI_RESPONSIVE_SKILL.md` se il task riguarda layout mobile.
4. `docs/per-ui-design-skill/UI_EDIT_SKILL.md` se il task riguarda stile/componenti.

## Divieti

- Non confondere Menu QR con Pagina Prenota.
- Non toccare flusso prenotazione se il task riguarda solo menu.
- Non cambiare schema dati menu senza skill DB e verifica senior.
- Non introdurre placeholder o fallback hardcoded senza tracciarli.

## Output minimo

- Flusso coinvolto.
- Skill lette.
- File letti.
- Cosa puoi toccare.
- Cosa non tocchi.
- Rischi e test previsti.
