# CalendarBackup report

Questa skill serve per chiudere una sessione in modo verificabile e utile a Matteo.

## Quando usarla

Usala quando Matteo dice:

- lavoro ok;
- fai report;
- report finale;
- dammi follow up;
- spiegamelo semplice;
- riepiloga;
- cosa hai fatto;
- cosa manca.

## Fonti da leggere

1. `docs/COMUNICAZIONE_UTENTE_SKILL.md`
2. `docs/Comunicazione-Skill/VOCABOLARIO.md`
3. `docs/FOLLOW_UP.md` se ci sono debiti, rimandi o follow-up
4. Skill d'area del lavoro appena svolto

## Regole

- Parla per schermate e flussi concreti.
- Separa file letti da file modificati.
- Separa test eseguiti da test non eseguiti.
- Non inventare comandi, log o risultati.
- Se non hai verificato qualcosa, dichiaralo.
- Non fare commit/push/merge salvo istruzione esplicita prevista dal vocabolario.

## Output minimo

- Obiettivo.
- File letti.
- File modificati.
- Modifiche effettuate.
- Test eseguiti con risultato reale.
- Test non eseguiti.
- Rischi residui.
- Follow-up.
- Conferma: nessun commit/push/merge, se vero.
